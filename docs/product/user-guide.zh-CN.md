# 评论采样台使用指南

[English](user-guide.en.md) · [架构说明](../architecture/architecture.zh-CN.md) · [平台限制](../platform-policy.md)

本文对应 0.1.0 版本。文中按钮名称与界面一致，状态名和错误码保留为代码中的写法。

## 1. 产品范围

评论采样台用于个人或小团队分析商品评论。它把不同平台的商品输入转成统一任务，保存可见评论，并提供关键词、评分和购买标记筛选，以及 CSV、JSON 导出。

四个平台当前的实际能力不同：

| 平台 | 可接受的输入 | 当前采集方式 | 主要限制 |
| --- | --- | --- | --- |
| 京东 | 数字商品 ID；`item.jd.com`、`item.m.jd.com` 商品链接 | 公开评论页面优先；用户同意后可用浏览器协助 | 公开通道可能限流、要求验证或改版 |
| 淘宝/天猫 | 数字 `itemId`；`item.taobao.com`、`detail.tmall.com`、`detail.tmall.hk`、`world.taobao.com` 商品链接 | 浏览器协助 | 自动 API 需要平台授权，本版本未内置授权 API 适配器 |
| 拼多多 | 数字 `goods_id`；支持的 `yangkeduo.com`、`pinduoduo.com` 商品链接 | 浏览器协助 | 需要平台授权或用户自行查看页面；本版本未内置授权 API 适配器 |
| Amazon | 10 位字母数字 ASIN；支持的 Amazon 地区站点商品链接 | 浏览器协助 | Creators API 不提供评论列表；页面内容受站点、地区和登录状态影响 |

“可以创建任务”不等于“能够取得全部评论”。平台是否提供评论、账号能看到什么范围、页面是否要求验证，都会改变结果。

同一件商品在不同平台通常有不同的商品 ID。请在目标平台分别建立任务，再使用导出文件做对照。当前没有跨平台商品合并或自动匹配功能，也没有 CSV/JSON 导入功能。

## 2. 安装与启动

### 2.1 环境要求

- Python 3.11 或更高版本。
- 京东公开通道不需要额外浏览器。
- 淘宝/天猫、拼多多、Amazon，以及京东转浏览器协助时，需要安装 Google Chrome。

在仓库根目录执行：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test,browser]'
.venv/bin/python -m review_sampler
```

随后打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。

请从仓库根目录启动。默认数据库和浏览器会话路径都相对于当前工作目录：

- 数据库：`runtime/review-sampler.sqlite3`
- 浏览器会话：`runtime/browser-state/<platform>/`

应用固定监听 `127.0.0.1:8765`，没有局域网监听参数，也没有用户登录或访问控制。不要把端口反向代理到公网。

### 2.2 更换数据库位置

需要把数据库放到其他目录时，在启动命令前设置 `REVIEW_SAMPLER_DB`：

```bash
REVIEW_SAMPLER_DB=/absolute/path/reviews.sqlite3 .venv/bin/python -m review_sampler
```

使用相对路径时，它同样相对于启动命令所在目录。

## 3. 用演示数据走一遍

先确认服务正在运行，然后：

1. 打开工作台。
2. 点击“载入演示”。
3. 工作台会创建一个包含 6 条评论的任务，并显示“已完成”。
4. 在“搜索评论”中输入 `打印`，点击“筛选”。
5. 把“评分”改为 `5 星`，再次点击“筛选”。
6. 点击“清除”恢复全部评论。
7. 保持任意一组筛选条件，分别点击“导出 CSV”和“导出 JSON”。

演示任务不会访问平台，用于确认页面、筛选和下载流程。最多可以载入 24 条内置演示评论；界面的“载入演示”按钮固定创建 6 条。

## 4. 创建真实任务

### 4.1 选择平台并填写商品

在页面顶部的平台栏选择目标平台。工具不会根据裸 ID 猜测平台；完整商品链接可以识别所属平台，但仍会检查所选平台是否与链接一致。

商品输入的规则如下：

| 平台 | 裸 ID | 链接要求 |
| --- | --- | --- |
| 京东 | 纯数字 | 主机必须是 `item.jd.com` 或 `item.m.jd.com`，路径中包含商品数字 ID |
| 淘宝/天猫 | 纯数字 | 主机必须是受支持的商品主机，查询参数中包含 `id=<数字>` |
| 拼多多 | 纯数字 | 主机必须是受支持的拼多多主机，查询参数中包含 `goods_id=<数字>` |
| Amazon | 10 位字母或数字，保存时转为大写 | 支持 `/dp/<ASIN>`、`/product/<ASIN>`、`/gp/product/<ASIN>` 和 `/product-reviews/<ASIN>` 页面 |

Amazon 链接的主机需要属于工具支持的 `.amazon.*` 地区站点。短链接不会在本地展开：`u.jd.com`、`m.tb.cn`、`p.pinduoduo.com`、`a.co`、`amzn.to` 等地址会提示粘贴最终商品页或原始 ID。请先在浏览器中打开短链接，再复制地址栏中的最终商品地址。

“最多保存”的范围是 1 到 5000。这个数字是任务保存上限，不保证平台有这么多可见评论。

### 4.2 评论方向

“评论方向”有三项：全部、负面优先、正面优先。它只用于京东公开评论通道，对应公开接口的方向参数。

淘宝/天猫、拼多多和 Amazon 的任务会禁用此选项。浏览器协助不会按语义分类评论；采集完成后可以按评分、关键词筛选，也可以导出后做进一步分析。

京东任务转到浏览器协助后，原方向参数不会限制页面内容。此时读取的是页面当前可见评论，仍需在结果中另行筛选。

### 4.3 浏览器同意

淘宝/天猫、拼多多和 Amazon 必须勾选“我会在打开的 Chrome 窗口中自行完成登录和验证”，然后点击“开始采样”。

京东可以选择是否勾选：

- 不勾选：只尝试公开评论通道。
- 勾选：公开通道遇到登录、验证或限流时，任务可以转用浏览器协助。

勾选的含义是同意工具在本机打开 Chrome，并把当前任务交给用户自行完成平台页面要求。工具不会接收账号密码，也不会自动处理验证码、滑块或登录按钮。

## 5. 浏览器协助怎么操作

浏览器协助使用独立的持久化 Chrome 配置目录，不读取日常 Chrome 的个人资料。第一次在某平台使用时，需要在这个新窗口中登录；之后同平台任务会复用 `runtime/browser-state/<platform>/` 中的会话。

1. 创建任务后，工具打开 Chrome 并加载商品页。
2. 任务进入“需要你处理”，原因会显示在任务区。
3. 切换到 Chrome 窗口，自行登录或完成平台要求的验证。
4. 打开该商品的评论或评价页面。对于淘宝/拼多多，评论内容需要在页面中实际加载出来；对于 Amazon，应进入可见的评价列表。
5. 回到工作台，点击“页面已处理，继续”。
6. 工具读取已经出现的评论，并执行有限次数的页面滚动。界面会继续轮询任务状态。
7. 如果再次遇到验证，任务重新进入“需要你处理”。完成页面操作后，再次点击“页面已处理，继续”。

浏览器辅助任务最多执行 8 轮滚动，每轮等待约 1 秒；连续两轮没有新增评论时提前结束。淘宝和拼多多的页面评论主要依赖页面加载的 JSON 响应，京东和 Amazon 还可以解析固定的评论页面结构。页面改版或接口字段变化后，可能提示无法识别可见评论。

开启浏览器协助后，会话目录可能包含身份 Cookie。请把 `runtime/` 当作私人数据目录，不要提交、上传或与他人共享。

### 5.1 京东公开通道被拦截时

如果创建京东任务时勾选了浏览器同意，遇到验证、拒绝访问或限流后，任务会尝试转到 Chrome。若页面要求登录或验证，按上一节的步骤完成并继续。

如果创建任务时没有勾选，后台不会打开 Chrome。遇到这类提示时，当前任务不会因为点击“页面已处理，继续”就获得新的登录会话。请等待平台限制解除后重试，或新建任务并勾选浏览器协助。

## 6. 任务状态

每个任务只处于以下七种状态之一：

| 状态 | 界面名称 | 含义 | 可执行操作 |
| --- | --- | --- | --- |
| `queued` | 排队中 | 任务已创建，后台执行器尚未开始或刚启动 | 可停止并保留已保存内容 |
| `running` | 采集中 | 正在请求接口或读取浏览器页面 | 可停止并保留已保存内容 |
| `needs_user` | 需要你处理 | 需要登录、验证、页面确认或授权 | 处理页面后点击“页面已处理，继续” |
| `interrupted` | 已中断 | 本地服务在任务运行期间停止 | 点击“继续任务” |
| `completed` | 已完成 | 当前通道到达结束条件或保存上限 | 查看、筛选和导出 |
| `failed` | 采集失败 | 遇到限流、网络、解析或通道错误 | 查看错误原因，点击“重试任务”或稍后再试 |
| `cancelled` | 已停止 | 用户主动停止任务 | 查看和导出已保存内容 |

“已完成”表示采集器按照当前通道的结束规则停止了，不等于平台一定没有更多评论。京东空结果、页面只显示一部分评论、达到任务上限或浏览器滚动到停止条件，都可能产生较少结果。

常见错误码：

| 错误码 | 常见原因 |
| --- | --- |
| `AUTH_REQUIRED` | 平台要求登录、账号权限或授权 |
| `VERIFICATION_REQUIRED` | 页面要求验证码、滑块或其他人工验证 |
| `RATE_LIMITED` | 请求过于频繁，重试后仍未恢复 |
| `NETWORK_ERROR` | 网络中断、超时或平台返回服务端错误 |
| `PARSE_ERROR` | 页面结构、接口格式或字段发生变化 |
| `UNSUPPORTED` | 当前运行环境缺少对应采集通道 |
| `INTERRUPTED` | 本地服务停止，任务等待恢复 |

失败响应不会把 Cookie、请求头或账号信息写进任务原因。已保存的评论也不会因为后续失败而删除。

## 7. 查看、筛选和导出

### 7.1 查看评论

在“最近任务”中选择任务。右侧会显示平台、商品 ID、任务上限、状态、已保存数量和评论记录。任务运行时，已经保存的评论可以继续查看。

评论正文按纯文本渲染，页面中的 HTML 标签和脚本不会作为页面元素执行。

### 7.2 筛选

筛选条件只作用于当前任务：

- “搜索评论”匹配作者、标题和正文。
- “评分”选择 1 到 5 星；平台没有评分的记录只会在“全部评分”下出现。
- “购买标记”选择“已验证购买”或“非已验证购买”。平台没有提供购买状态时，记录只在“全部”下出现。

点击“筛选”应用条件，点击“清除”恢复未筛选结果。筛选结果每次先显示 100 条，可以点击“再显示 100 条”继续加载。

京东的“评论方向”是采集时的请求参数，不会出现在右侧筛选器中。浏览器协助通道也不推断评论正负情绪。

### 7.3 导出

“导出 CSV”和“导出 JSON”会带上当前的关键词、评分和购买标记筛选。导出在点击链接时读取当时已经保存的数据；运行中的任务可以导出部分结果。

CSV 字段固定为：

```text
platform, product_id, platform_review_id, author, title, content,
rating, created_at_text, created_at, variant, verified_purchase,
helpful_count, source_url
```

CSV 使用 UTF-8 BOM，便于表格软件识别中文。文本以 `=`、`+`、`-` 或 `@` 开头时，会在最前面加单引号，避免被电子表格当成公式执行；NUL 字符会被移除。

JSON 的结构是：

```json
{
  "task": {
    "id": "...",
    "platform": "jd",
    "product_id": "...",
    "status": "completed"
  },
  "reviews": []
}
```

JSON 保留原始文本，不会添加 CSV 公式保护字符。把 JSON 数据再导入电子表格时，仍需把它当作不可信文本处理。

导出文件可能包含用户昵称、购买标记和评论正文。分享文件前请检查内容，并遵守平台条款和适用法律。

## 8. 服务重启与任务恢复

正在排队或运行的任务遇到服务停止后，下次启动会被标记为“已中断”。已经写入数据库的评论仍在：

1. 重新启动 `.venv/bin/python -m review_sampler`。
2. 打开原任务。
3. 点击“继续任务”。

京东公开通道会从任务保存的页码继续。浏览器协助会重新打开页面并读取当前可见内容；相同评论由去重规则处理，不会因为再次看到而重复保存。平台登录状态可能已经失效，任务会再次进入“需要你处理”。

失败任务可以点击“重试任务”。如果失败原因是持续限流，应先等待平台给出的冷却时间；如果页面结构已变化，需要更新对应解析器后再试。

## 9. 本地数据与会话清理

默认数据位置：

| 数据 | 路径 | 内容 |
| --- | --- | --- |
| 任务与评论 | `runtime/review-sampler.sqlite3` | SQLite 数据库，配置 WAL 时还会出现 `-wal`、`-shm` 文件 |
| 浏览器会话 | `runtime/browser-state/<platform>/` | Playwright 持久化 Chrome 配置、Cookie 和站点本地存储 |

数据库和浏览器会话都在 `.gitignore` 中。删除它们前先停止服务。

清除某个平台的登录状态：

```bash
rm -rf runtime/browser-state/jd
```

把路径末尾的 `jd` 换成 `taobao`、`pdd` 或 `amazon`，即可清理对应平台。不要让服务在操作期间继续使用该目录。

清空所有本地任务、评论和浏览器会话：

```bash
rm -rf runtime
```

这个命令会删除全部本地数据，不能撤销。需要保留记录时，先停止服务，再备份数据库文件；运行中直接复制 SQLite 的 WAL 数据库可能得到不一致的副本。

当前版本没有在界面中提供“清除会话”按钮，也没有会话加密。操作系统账户权限是这些文件的最后一道保护。

## 10. 常见问题

### 浏览器没有打开

确认本机安装了 Google Chrome，并重新加载页面。平台能力信息会根据当前环境显示是否检测到 Chrome。没有 Chrome 时，淘宝/天猫、拼多多和 Amazon 不能创建浏览器任务。

### 任务一直显示“需要你处理”

切换到打开的 Chrome 窗口，完成登录或页面验证，并先打开评论列表。回到工作台后点击“页面已处理，继续”。如果这个京东任务开始时没有勾选浏览器同意，应新建任务。

### 任务已完成但评论很少或为零

先检查商品页和评论列表是否对当前账号、地区开放。京东公开通道可能只返回部分可见评论；浏览器最多滚动 8 轮；页面也可能在连续两轮没有新增后停止。可以查看任务原因，重新建立任务并选择一个足够的上限。

### 提示无法识别可见评论

可能是评论列表尚未加载、页面要求登录，或平台改版后 DOM、JSON 字段发生了变化。先确认浏览器页面能看到评论，再继续任务；仍然失败时，需要更新采集器或解析别名。

### 提示限流

停止重复重试，等待一段时间。工具会对 HTTP 429、临时网络错误和服务端错误进行有限退避；它不会更换代理来继续请求。

### 为什么淘宝、拼多多没有直接 API

可用的自动接口需要平台应用、账号权限或商家授权。当前仓库没有内置这些凭证和适配器，因此不能提供未经授权的 API 采集。浏览器协助只读取用户在当前页面已经能查看的内容。

### 为什么 Amazon 不使用 Creators API 抓评论

Creators API 的 `GetItems` 不提供评论列表。它能用于商品元数据，但不能替代评论采集。当前版本的 Amazon 通道是浏览器协助。

### 能导入平台导出的 CSV 吗

不能。当前版本没有导入接口或导入按钮。示例文件 `src/review_sampler/static/fixtures/demo_reviews.csv` 只用于说明导出列和公式安全写法。

## 11. 故障排查与技术检查

运行测试：

```bash
.venv/bin/pytest -q
```

检查前端脚本语法：

```bash
node --check src/review_sampler/static/app.js
```

本地 API 文档位于 [http://127.0.0.1:8765/docs](http://127.0.0.1:8765/docs)。它仅用于本机调试，不应暴露给其他设备。

默认测试只使用固定响应和页面夹具，不会访问线上平台。它们能检查解析和状态逻辑，不能证明某个平台的页面今天仍可用。
